# Archived benchmark results (by version)

Each `benchmark-results-<version>.csv` is the frozen ORM-comparison dataset for that litedbmodel release.
The **live** dataset is `../benchmark-results.csv` (regenerated by `benchmark/benchmark.ts`); the docs
(`docs/BENCHMARK.md`, `docs/COMPARISON.md`, `docs/benchmark-chart.svg`) are machine-generated from the
live file. When a release ships, snapshot the live file here as `benchmark-results-<version>.csv` so an
external reader can tell which release a set of numbers belongs to and old numbers never masquerade as current.
